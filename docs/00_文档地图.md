## 四、命名规范建议

现有命名混用 `day1_guide`、`day3收尾_day4_清单`、`week2_任务清单`、`7_9_今日计划` 等多种风格。建议体系如下（**总纲层已应用**，天指引/收束类保持原名）：

| 层级 | 规范 | 现状 | 建议名 |
|------|------|------|--------|
| 总纲 | `00_总纲_<主题>.md` | ✅ 已应用 | `00_总纲_路线.md` · `00_总纲_资料索引.md` |
| 周总览 | `weekN/README.md`（保持） | 已合规 | 不变 |
| 天指引 | `weekN/dayX_<主题>.md` | 保持原名 | `day1_API入门.md` |
| 周收束 | `weekN/weekN_串讲.md` | 已合规 | 不变 |
| 全局收束 | `99_收束_<主题>.md` | 保持原名 | `99_收束_培训分享.md` |
| 临时 | 移 `tmp/` 或加 `_tmp` 后缀 | 待清理 | 移 tmp/ |

> **重命名范围**：本次只对总纲层 2 篇做轻量重命名（`企业级Agent开发加速路线` -> `00_总纲_路线`、`培训路线图分析` -> `00_总纲_资料索引`），已同步更新 11 个引用文件、无死链。天指引/收束类保持原名，避免大面积改链接的死链风险；待 8/21 路线收尾时可一次性整理。

## 六、行业报告贴合度速查

> 12 家 AI Agent 行业公司报告与"企业级 Agent 开发入门 + 智能制造排程排产 demo"的贴合度。完整逐一说明见 [`hangye/README.md`](hangye/README.md)。

**最贴合：中科闻歌** - 12 家里唯一明确基于 **Harness 架构**（Claworks）的厂商，叠加 Decitron 决策推演 + 多智能体 + 工业物流调度大客户（中石化/海尔/比亚迪），命中"刚追加 Harness 目标 + week4 多 Agent/鉴权 + 制造业"。

按维度次选：**拉普拉斯AI**（排产场景最同构）、**语核科技**（长任务控制最命中）、**卓世科技**（设备 OT 层最对口）、**壹沓科技**（工程化最完整）。

| 公司 | 贴合度 | 一句看点 |

## 七、延伸学习：Claude Code 解剖（learn-claude-code）

> 7 周理论路线（用 SDK 从零搭 Agent）完成后，进入 **learn-claude-code** 解剖 Claude Code 本身的 **Harness 实现**——正好补 [课程提炼](courses/从能回答到能办事-重点提炼.md) 里的「核心增量①Harness 工程」。平级项目：[`projects/learn-claude-code`](../../learn-claude-code)（从 `s01_agent_loop` 读到 `s20_comprehensive`）。

**定位差异**：agent-training 教「用模型 + SDK 搭 Agent」（应用层）；learn-claude-code 教「解剖 Claude Code 的 Harness 怎么造」（工程架构层）。先用 -> 再懂底层。

| 章 | 主题 | 核心机制 | 对应 7 周路线 / 课程目标 |
|----|------|---------|------------------------|
| s01 | Agent Loop | `messages` / `while True` / `stop_reason` | week1 API 循环的底层 |
| s02 | Tool Use | dispatch map / 并发 | week3 MCP 工具调度原型 |
| s03 | Permission | `PermissionRule` / 审批管线 | 课程「可控」=权限边界 |
| s04 | Hooks | `PreToolUse` / `PostToolUse` | Harness 扩展点 |
| s05 | TodoWrite | 先计划后执行 | 课程「长任务步骤控制」 |
| s06 | Subagent | fresh messages / 上下文隔离 | week4 多 Agent 隔离 |
| s07 | Skill Loading | `SkillManifest` / 按需注入 | 技能系统 |
| s08 | Context Compact | snip/micro/budget/auto 四层 | 课程「上下文工程」 |
| s09 | Memory | selection/extraction/consolidation | 持久记忆 |
| s10 | System Prompt | 运行时组装 / 分段拼接 | 提示工程进阶 |
| s11 | Error Recovery | token 升级 / fallback / 重试 | week1 主备 fallback 的源头 |
| s12 | Task System | `blockedBy` / 磁盘持久化 | 长任务编排 |
| s13 | Background Tasks | 线程执行 / 通知队列 | 异步执行 |
| s14 | Cron Scheduler | 持久化调度 / 会话级触发 | 定时任务 |
| s15 | Agent Teams | `MessageBus` / 权限冒泡 | week4 多 Agent 协作 |
| s16 | Team Protocols | 关机握手 / 计划审批 | 多 Agent 治理 |
| s17 | Autonomous Agents | 空闲循环 / 自动认领 | 自主性 |
| s18 | Worktree Isolation | `WorktreeRecord` / 任务-目录绑定 | 并行改码隔离 |
| s19 | MCP Plugin | 多传输 / 通道路由 / 工具池 | week3 MCP 进阶 |
| s20 | Comprehensive | 全部机制归到一个循环 | 总收官 |

**推荐读法**：先 s01/s02/s05/s08（Agent 循环 + 工具 + 计划 + 上下文压缩，构成 Harness 骨架），再按 7 周路线触点跳读 s03/s06/s11/s15，最后 s20 收口。中文 README：[`learn-claude-code/README-zh.md`](../../learn-claude-code/README-zh.md)。
