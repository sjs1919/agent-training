# 行业深度分析报告 · 阅读导航

> 12 家 AI Agent 行业公司深度分析报告。本导航标注每家与"企业级 Agent 开发入门 + 智能制造排程排产 demo"的贴合度，并给出阅读顺序。
>
> **选报告依据**：用户当前 week4（多 Agent + 鉴权），载体是 3D打印/CNC 排程排产 demo，刚追加 **Harness 工程 / 业务数据包 / 长任务步骤控制** 三个学习目标，本职在智能制造行业。

---

## 一句话结论

**最贴合：中科闻歌（Wenge）**--12 家里唯一明确基于 **Harness 架构**（Claworks 企业级 Agent 操作系统）的厂商，叠加 Decitron 决策推演（可映射排产决策）、多智能体、工业与物流调度大客户（中石化/海尔/比亚迪），与"刚追加 Harness 目标 + week4 多 Agent/鉴权 + 制造业"多点命中。

**按维度次选**（若聚焦单一维度）：

| 维度 | 首选 | 理由 |
|------|------|------|
| 场景最同构 | **拉普拉斯AI** | 粉末冶金排产案例（订单准时率 75%->98%），与 3D打印/CNC 排程排产几乎同构 |
| 长任务控制最命中 | **语核科技** | 制造业垂直，置信度/目标锚点/规划-执行-评估-修正螺旋循环 |
| 设备 OT 层最对口 | **卓世科技** | NextClaw 下沉 ROS2/Modbus/MQTT，直接对应 3D打印/CNC 设备控制 |
| 工程化最完整 | **壹沓科技** | 小沓 OS 任务拆解/流程控制/权限/校验 + CubeFlow 可观测 |

## 推荐阅读顺序

1. **中科闻歌** ⭐ - Harness 架构 + 决策推演，对照刚追加的 Harness 目标
2. **拉普拉斯AI** - 排产场景同构，对照 week3-4 的 MCP/编排
3. **语核科技** - 长任务步骤控制，对照追加的长任务控制目标
4. **卓世科技** - 设备 OT 层，对照 3D打印/CNC 设备控制
5. **壹沓科技** - 工程化最完整，对照 Harness 编排/权限/可观测
6. **来也科技** - 治理工程，对照鉴权/审计
7. **AutoAgents.AI** - 企业级 Agent 标杆，对照 Multi-Agent 编排
8. 衔远科技 / 红熊AI - 按需，看 Harness 评测 / 记忆 MCP
9. 日行迹智能 / 句子互动 / 心识宇宙 - 低优先，时间富余再看
