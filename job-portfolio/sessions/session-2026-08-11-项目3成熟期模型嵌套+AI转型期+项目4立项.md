### 3. 成熟期模型嵌套（核心产出）

**扩散路径**（从开发组单点突破→涟漪式扩张）：

```
开发组双周迭代（建流程后半段启动，约3月基础设施+3月运转）
   │ 3月后 → 产品团队纳入（向前2周锚点）
   │ 6月后 → 测试团队纳入（产品跑3月后）
   │ → 绩效模型数据积累 → V1→V4迭代
   │ → 业务对齐：月度目标+业务研发双周例会 → 黑盒变透明
   │ → 人才盘点：价值观+绩效双维度 → 识别骨干
   │ → 项目负责人制度：人才培养器
   │ → 人的产出：4主管+3骨干+1连续晋升
```

**核心设计逻辑「让制度自己长出来」**（已写入稿子管理背景）：

```
双周迭代产生任务数据
   ├→ 识别大/跨组任务 → 催生 项目负责人制度
   │                          └→ 绩效模型增加"项目负责人激励"维度
   ├→ 测试纳入，产出质量数据 → 绩效模型增加"质量考核"维度
   └→ 绩效跑半年，人的数据丰满 → 催生 人才盘点
                                      └→ 识别骨干 → 送做项目负责人
                                              └→ 正向反馈：人成长+项目顺畅
```
