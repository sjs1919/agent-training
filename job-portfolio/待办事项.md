## 维护规则（统一管理）

**1. 新增待办 → 追加登记**
- 对话中一旦出现待办事项（用户提及 / 讨论中产生 / 完成后剩余未完成项），**立即追加**到本文件对应分类（A 话术 / B 简历 / C 素材 / D 求职支持 / E demo 线），不遗漏
- 新增项：编号续用该分类下一个序号，日期 = 当天，优先级（P0-P3），状态 = 📋

**2. 处理完成 → 登记结果**
- 事项处理完毕，**登记完成日期 + 状态**：从「活跃待办」区移到「已归档 / 已完成」区，标 ✅
- 更新「最后更新」日期

**3. 分类与优先级**
- 按 5 类归档：A 面试话术（求职核心）/ B 简历 / C 素材补充 / D 求职支持 / E demo 线（技术开发，非求职主线）
- 优先级：P0（必做，面试露馅风险）/ P1（应该做，提升竞争力）/ P2（锦上添花）

**4. 完成后不删除**，只标记 ✅，保留追溯
