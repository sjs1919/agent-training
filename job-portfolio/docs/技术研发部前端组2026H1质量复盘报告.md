> **章节摘要**：本章节为前端组（陈美琴、黄暖钦、叶建奇）建立基于 Bug 加权密度的组长质量 KPI 评分模型。通过量化 Bug 严重程度权重、剔除迭代日后的有效工作日，计算团队人均日均密度，并以此为基准进行绩效评分。旨在客观衡量前端组月度质量表现，识别异常月份，为组长管理提供数据支撑。

### 5.1 计算公式说明

**5.1.1 Bug 加权得分**

```text
Bug 加权得分 = Σ(Bug数量 × 严重度权重)
```

| 严重度 | 权重 |
|:------:|:----:|
| 1级（致命） | 250 |
| 2级（严重） | 50 |
| 3级（一般） | 10 |
| 4级（建议） | 1 |

**5.1.2 有效工作日**

```text
有效工作日 = 本月工作日 - 迭代日（每2周1天）
```

迭代日基于最新迭代日 **2026-06-17** 倒推，每14天1个迭代日。

**5.1.3 个人日均密度**

```text
个人日均密度 = 个人 Bug 加权得分 / 有效工作日
```

**5.1.4 团队人均日均密度**

```text
团队人均日均密度 = 团队 Bug 加权总分 / 有效工作日 / 活跃人数
```

> 活跃人数：当月有 Bug 数据的成员数（如 2026-05 陈美琴无 Bug，活跃人数=2）。

**5.1.5 团队绩效得分**

```text
团队绩效 = 取整(75 + (8.2 - 团队人均日均密度) × 5)
```

| 得分范围 | 说明 |
|:--------:|------|
| > 75 | 🟢 加分（密度低于基准 8.2） |
| = 75 | ⚪ 持平（密度等于基准 8.2） |
| < 75 | 🔴 扣分（密度高于基准 8.2） |

**5.1.6 个人状态**

```text
个人状态 = 🟢 加分（密度 < 8.2） / 🔴 扣分（密度 > 8.2） / ⚪ 持平（密度 = 8.2）
```
