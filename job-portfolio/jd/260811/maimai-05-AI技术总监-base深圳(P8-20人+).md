## 工作职责
1. 负责 AI 产品的业务研发工作，包括但不限于技术架构规划、业务实现、整体需求管理，带领团队在技术侧实现业务目标；
2. 负责团队技术规范制定工作，包括相关技术标准和流程；
3. 负责团队技术研究及技术难点攻坚；
4. 负责团队建设和管理，建立完善的人员管理、培养机制。

## 任职资格
1. 本科及以上学历，计算机、算法、数据等相关专业，5 年及以上工作经验，有超过 20 人以上研发团队管理经验；
2. 有 AI 产品落地经验，对 AI 技术的发展和应用有浓厚兴趣，熟悉当前各大模型的能力和应用场景；
3. 熟悉系统架构设计，对高并发、高可用架构系统有正确、深刻的理解，有分布式服务设计或开发经验者优先；
4. 熟悉常用的开源框架，精通 PHP / Java / C++ / Go / Python 其中一种编程语言，在相关重要开源社区具备贡献经历的优先；
5. 对技术有激情，喜欢钻研，能快速接受和掌握新技术，能解决工作中的技术难点；关注产品，以客户为中心的思维；
6. 知名互联网公司、SAAS 行业背景优先。
