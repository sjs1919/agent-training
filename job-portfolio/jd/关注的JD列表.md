### 1. AI应用负责人（Cursor 全链路 / 百万级 Agent）
- **来源**：猎聘 ｜ [原文链接](https://m.liepin.com/job/1984094843.shtml)
- **公司方向**：AI 电子领域，Cursor 全链路搭建
- **薪资**：70-100k/月（需登录确认）
- **岗位亮点**：
  - 百万级用户 AI Agent 高并发分布式系统设计
  - VS Code 类客户端 → 后端胶水服务 → 行业技能库 → 通用大模型调用，完整产品链路
  - 带客户端/后端/算法跨职能团队
  - **无需负责大模型微调**——偏工程化落地，非算法研究
- **任职硬要求**：本科+、5年+ AI应用/后端架构、百万级高并发实战、带队能力
- **加分项**：Cursor/CodeGeeX/Copilot 研发经验、大规模 AI 会话集群、VS Code 插件经验
- **与苏坚生匹配度**：
  - ✅ 强匹配：AI 编程团队交付（lexy 商城）、多 Agent 工程化（排产助手）、跨职能团队管理（150+人）、高并发系统（600亿放款平台）
  - ⚠️ 需补强：VS Code 插件交互、百万级 Agent 并发调度（当前为团队级验证）
  - ✅ 优势：无需大模型微调，正好规避纯算法研究硬缺口
- **投递版本建议**：AI落地版（项目4 lexy + token-hub + Agent排产 三线齐发）

### 2. AI总监（AI一号位 / 汇报 CTO）
- **来源**：猎聘 ｜ [原文链接](https://www.liepin.com/a/72177449.shtml)
- **公司方向**：集团级 AI 战略统筹，汇报集团互联网 CTO
- **薪资**：50-80k/月 · 14 薪（猎聘公开页标注）
- **岗位亮点**：
  - 集团 AI 一号位，统筹 AI 战略规划与落地执行
  - 深入核心业务线（AI coding、企业流程、财务流程）梳理并验证 AI 应用场景
  - 主导 AI 项目 0→1 全流程：需求拆解 → 方案设计 → 实施 → 迭代优化
  - 跨部门协调整合资源，推动 AI 与业务深度融合
- **任职硬要求**：精通大模型核心能力/技术边界/落地逻辑、可验证的 AI 落地成功案例、完整项目闭环经验、强执行力+躬身入局
- **与苏坚生匹配度**：
  - ✅ 强匹配：AI coding 落地（lexy 商城 4 周交付）、AI 项目 0→1 全流程（Agent 排产 4 周验证）、跨部门协同（6 场培训+双周例会）、躬身入局（技术管理者亲自下场验证）
  - ✅ 强匹配："完整项目闭环"——lexy 商城从需求到上线 + Agent 排产从验证到团队赋能
  - ⚠️ 需补强：集团级 AI 战略统筹（当前为部门级），可在面试中补"从部门到集团"的规划思路
  - ✅ 优势：学历/年限门槛宽松（未强制博士），"本科+20年+规模化落地"画像完全 fit
- **投递版本建议**：AI落地版——重点突出"躬身入局 0→1"叙事，价值主张对齐"AI coding + 企业流程 + 跨部门协同"
