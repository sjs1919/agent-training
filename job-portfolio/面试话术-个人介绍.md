## 基本版（2 分钟版）

> 我是苏坚生，金蝶、腾讯起步的研发管理者，Java 架构师出身，带过 150+ 人跨职能团队，历经五个行业。
>
> 做管理这么多年，我带过三段团队：绿信和 AI 团队都是从 0 到 1 建起，未来工场是空降整合跨职能团队。其中未来工场是空降整合 6 职能团队：产品、Java、测试等，1 月摸底、半年优化、1 年步入正轨。绿信是从 0 到 1：5 年半时间，建起百余人研发队伍，支撑 600 亿放款规模，3 年晋升研发中心总监。
>
> 2025 年起我主动转型 AI 工程化：先用 Vibe Coding 方法论个人交付 2 个全栈项目，再组建 AI 编程团队交付生产级商城，Python 做实验验证、Java 做工程落地。Agent 方向我系统实战了全链路：从 ReAct 循环到多 Agent 协作，再用制造业排程排产场景验证落地可行性。
>
> 在未来工场 4 年经历 A 轮到业务成熟，近期公司战略调整、AI 投入收窄，我想找一个愿意在 AI 工程化持续投入的平台，把技术管理和 AI 实践结合起来创造价值。

**时长**：~335 字 / ~111 秒 ≈ 1 分 50 秒（目标 2min，略短留余量）

**结构**：
- 第 1 段（身份标签 + 大厂背书）：第 1 句
- 第 2 段（管理维度，核心 ~50%）：第 2-4 句
- 第 3 段（AI 工程化转型 ~35%）：第 5-6 句
- 第 4 段（收尾钩子 ~15%）：第 7 句

## 追问锚点准备

### 数字口径
- **150+ 人跨职能团队**：绿信峰值（能力上限背书，第 1 句定调）
- **百余人研发队伍**：绿信研发队伍（前精确后模糊，避免数字冲突；被问具体答 180）
- **6 职能团队**：产品/OMS/Java/测试/大数据/运维（话术列 3 代表：产品、Java、测试）
- **1 月摸底/半年优化/1 年正轨**：未来工场空降整合节奏（话术用"优化"包装"汰换"，被问细化汰换依据）
- **5.5 年**：绿信任职（2016.11-2022.03）
- **600 亿放款**：绿信业务规模
- **3 年晋升**：绿信 3 年不到晋升研发中心总监
- **2 个全栈项目**：Vibe Coding 个人实践（Go LLM 网关 / Vue3+FastAPI 复盘系统）；规格驱动（spec->plan->task 三件套）是 Vibe Coding 方法论核心，非项目
- **4 年**：未来工场任职（2022.04-至今）

### AI 演进锚点（被问"怎么转的"）
- 2025 年 Cursor 代码补全 -> Claude Code 出来后构建 Vibe Coding 方法论 -> 确认后公司内部推进 -> 晋级 Agent 学习实践
- 话术不讲"薪资驱动晋级 Agent"，包装"Vibe Coding 验证后往 Agent 工程化晋级，往价值链上游走"

### Vibe Coding 方法论锚点（被问"方法论是什么"）
- 三要素：规格驱动（spec->plan->task 三件套）+ 多 AI 工具分工（Claude/Trae/CodeGraph）+ 四防线验收
- 价值：约束 AI 协作，从"会用 AI 工具"升级为"工程化约束 AI 协作"，可复制到团队

### Agent 全链路锚点（被问"Agent 到什么深度"）
- ReAct 循环 -> LangGraph StateGraph 编排 -> 多 Agent Supervisor 协作 -> Token Exchange(RFC 8693) 鉴权 -> RAGAS 评估
- 被问"ReAct 是手写的吗"：底层 ReAct 循环手写理解原理，生产代码 AI 产出，通过工程化和架构能力优化
- 被问"现在还手写代码吗"：AI 写代码，我做架构决策和算法优化

### 制造业落地锚点（被问"制造业怎么落地"）
- 3D 打印/CNC 排程排产场景
- 合同赔付/航天件全检等业务细节
- 团队级验证（非规模化）

### 当前管理半径（被问"现在带多少人"）
- 话术不主动报现状 10 来人（公司调整结果，非能力缩水）
- 被问答："公司调整后聚焦核心，管理 10 来人核心骨干"
- 历史峰值 150+ 定能力上限

**场景索引**：

### 1. 猎头首聊版（30 秒）✅ 定稿 v3

> 我是苏坚生，金蝶、腾讯起步的研发管理者，目前在未来工场任研发总监，带过 150+ 人团队，历经五个行业。这 4 年经历 A 轮到业务成熟完整周期；2025 年起主动转型 AI 工程化，从个人实践、组建 AI 团队到 Agent 全链路实战。近期公司战略调整、AI 投入收窄，看研发总监或技术 VP 机会，想找愿意在 AI 工程化持续投入的平台。

**裁剪说明**：销售化重写（非裁短）。卖点 = 研发总监 title + 在职看机会 + AI 工程化亮点 + 战略调整动机 + 岗位意向（研发总监/技术 VP，与 HR 版同口径）。薪资/到岗不入正文（猎头问才答，避免亮底牌被压价），见下方「猎头问询应答口径」。

**猎头问询应答口径**（备查，不入话术正文）：
- 薪资期望：现金 70-80 万（猎头问才答）
